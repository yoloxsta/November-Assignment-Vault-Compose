# Task Management App with Vault

A complete 3-tier application with enterprise-grade security using HashiCorp Vault for dynamic database credentials.

---

## Architecture

```
┌──────────────────┐
│  React Frontend  │  http://localhost:5173
│  Modern UI/UX    │
└────────┬─────────┘
         │ HTTP API
         ▼
┌──────────────────┐
│  Node.js Backend │  http://localhost:3000
│  REST API        │
└────────┬─────────┘
         │ PostgreSQL Protocol
         ▼
┌──────────────────┐
│   PostgreSQL     │  localhost:5432
│   Database       │
└────────┬─────────┘
         │ Dynamic Credentials
         ▼
┌──────────────────┐
│  Vault Server    │  http://localhost:8200
│  Secrets Mgmt    │
└──────────────────┘
```

Key Feature: Database credentials are dynamically generated by Vault, rotate every hour automatically!

---

## Quick Start

### 1. Start All Services

```powershell
# Start everything
docker-compose up -d --build

# Wait 30 seconds for startup
Start-Sleep -Seconds 30
```

### 2. Configure Vault Database Engine

```powershell
# Setup Vault for PostgreSQL dynamic credentials
bash setup-vault-db.sh
```

### 3. Initialize Database Schema

```powershell
# Create database tables
Get-Content postgres\init.sql | docker exec -i vault-postgres psql -U postgres -d vault_demo
```

### 4. Restart Backend

```powershell
# Restart backend to connect to database
docker-compose restart backend
Start-Sleep -Seconds 10
```

### 5. Open the Application

```powershell
# Frontend
start http://localhost:5173

# Vault UI
start http://localhost:8200/ui
# Token: dev-only-token
```

## How Vault Integration Works

### Traditional Approach (INSECURE)
```javascript
// Hardcoded credentials in config file
const pool = new Pool({
  user: 'admin',
  password: 'password123'  // Visible in code!
});
```

### Your Approach (SECURE)
```javascript
// Dynamic credentials from Vault
const creds = await vault.read('database/creds/app-role');
// Returns: {username: 'v-token-abc123', password: 'random'}

const pool = new Pool({
  user: creds.username,     // Dynamic
  password: creds.password  // Never in code
});
```

### Credential Lifecycle

1. App starts → Requests credentials from Vault
2. Vault generates → Creates unique PostgreSQL user: v-token-xxxxx
3. App connects → Uses credentials to connect to database
4. Auto-expires → Credentials valid for 1 hour
5. Auto-renews → Backend renews at 48 minutes with NEW credentials

## Testing

### Test API

```powershell
# Get all tasks
curl http://localhost:3000/api/tasks

# Create task
curl -X POST http://localhost:3000/api/tasks `
  -H "Content-Type: application/json" `
  -d '{"title":"New Task","priority":"high"}'

# Get stats
curl http://localhost:3000/api/stats

# Test database connection
curl http://localhost:3000/api/db/test
```

### Test Vault

```powershell
# Generate credentials manually
docker exec vault-server sh -c "VAULT_TOKEN=dev-only-token vault read database/creds/app-role"

# View dynamic users in PostgreSQL
docker exec vault-postgres psql -U postgres -d vault_demo -c "\du"
```

## Security Benefits
